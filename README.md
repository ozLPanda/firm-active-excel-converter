# Satu.kz Excel Converter

Конвертер берет исходный Excel-прайс и создает workbook для импорта на satu.kz с листами `Export Products Sheet` и `Export Groups Sheet`.

Главное требование проекта - совместимость с импортом satu.kz.

## Что делает приложение

- Читает многостраничный Excel-прайс: каждый лист считается исходной группой товаров.
- Определяет колонки по заголовкам, а не по фиксированным номерам.
- Перед выгрузкой показывает окно проверки групп.
- Позволяет отредактировать название группы на выходе и ID группы.
- Сохраняет подтвержденные группы в `group_cache.json` и подставляет их в будущих запусках.
- Проверяет коды товаров и цены перед экспортом.
- Обрабатывает дубли артикулов.
- Нормализует единицы измерения под допустимые значения satu.kz.
- Экспортирует встроенные изображения товаров из исходного Excel.
- Создает итоговый файл с листами `Export Products Sheet` и `Export Groups Sheet`.

## Входной Excel

Каждый товарный лист должен содержать заголовки вроде:

- `код`, `Код товара`, `Артикул`;
- `Наименование`, `Название`, `Товар`;
- `Ед. изм`;
- `Остаток`, `Наличие`;
- `Цена розница`, `Цена`;
- цена для постоянных клиентов или оптовая цена, если она есть.

Конвертер ищет строку заголовков автоматически и использует найденные колонки.

## Группы

Перед экспортом открывается окно проверки групп:

- показывает все найденные исходные листы;
- позволяет изменить название группы на выходе;
- позволяет указать ID группы;
- ID группы хранится как текст, например `9450002`;
- подтвержденные значения сохраняются в `group_cache.json`.

Товары из групп без ID не экспортируются. Такие группы также не добавляются в `Export Groups Sheet`.

## Проверка кода и цены

Перед экспортом GUI показывает окно `Проверка кода и цены`, если найдены проблемные строки.

Некорректная цена:

- пустая;
- не является числом;
- равна `0`.

Некорректный код:

- пустой;
- `0`;
- состоит только из нулей, например `0000`;
- похож на служебный заголовок: `код`, `код товара`, `артикул`.

В итоговый файл попадают только товары с валидным кодом и ценой больше нуля. Неправленные строки пропускаются и отражаются в финальном сообщении.

## Дубли артикулов

Если один артикул встречается несколько раз:

- при одинаковом названии конвертер может оставить первую запись автоматически;
- при разных названиях GUI спрашивает, какую запись оставить;
- CLI для конфликтующих дублей завершает работу с понятной ошибкой.

## Служебные слова в названии

Конвертер удаляет служебные маркеры наличия из названия без учета регистра:

- `НЕТ В НАЛИЧИИ`;
- `ПОД ЗАКАЗ`.

Например:

```text
НЕТ В НАЛИЧИИ Группа безопасности компакт 3 бар
```

превратится в:

```text
Группа безопасности компакт 3 бар
```

Статус наличия при этом определяется как `Нет в наличии` или `Под заказ`.

## Заполняемые колонки satu.kz

Конвертер заполняет колонки через имена из `satu_schema.json`, а не через номера:

- `Код_товара`;
- `Название_позиции`;
- `Цена`;
- `Оптовая_цена`;
- `Минимальный_заказ_опт`;
- `Номер_группы`;
- `Название_группы`;
- `Уникальный_идентификатор`;
- `Единица_измерения`;
- `Наличие`;
- `Количество`, если есть числовой остаток.

`Уникальный_идентификатор` всегда равен `Код_товара`.

`Оптовая_цена` использует исходную оптовую цену, если она найдена, иначе обычную цену.

## Единицы измерения

Единица измерения приводится к допустимым значениям satu.kz.

Примеры нормализации:

- `компл`, `комп`, `комплекты` -> `комплект`;
- `м2`, `м²`, `квм` -> `кв.м`;
- `м3`, `м³`, `кубм` -> `куб.м`;
- `шт` -> `шт.`;
- `упак` -> `упаковка`;
- неизвестные значения -> `шт.`.

## Изображения из Excel

Если в исходном workbook есть встроенные изображения товаров, конвертер экспортирует только изображения тех товаров, которые реально попали в `Export Products Sheet`.

Правила:

- папка создается рядом с итоговым workbook;
- имя папки: `<имя_выходного_файла>_images`;
- имя изображения строится по `Код_товара`, например `00000001405.png`;
- если у одного товара несколько изображений, добавляются суффиксы `_2`, `_3`;
- старые файлы в папке изображений очищаются перед новым экспортом;
- декоративные бейджи вроде красного `NEW` не экспортируются.

## Удобства GUI

В окне проверки групп и других полях ввода работают:

- `Ctrl+C`, `Ctrl+X`, `Ctrl+V`, `Ctrl+A`;
- `Shift+Insert`;
- контекстное меню ПКМ: вырезать, копировать, вставить, выделить все.

Горячие клавиши работают и при русской раскладке.

Окна приложения открываются по центру экрана. Таблицы с большим количеством строк поддерживают прокрутку колесиком мыши.

## Запуск GUI

```powershell
cd C:\Users\admin\Desktop\active-firm\converter
python .\gui.py
```

В окне выберите:

- исходный прайс;
- путь финального файла.

После успешной конвертации приложение покажет путь до результата.

## Запуск CLI

```powershell
cd C:\Users\admin\Desktop\active-firm\converter
python .\converter.py "..\Прайс.xlsx" -o ".\output\satu-products.xlsx"
```

CLI подходит для автоматических прогонов. Конфликтующие дубли с разными названиями в CLI считаются ошибкой, потому что без GUI нельзя безопасно выбрать правильную запись.

## Конфигурация

`satu_schema.json` содержит:

- порядок и имена колонок листа `Export Products Sheet`;
- структуру листа `Export Groups Sheet`.

`group_aliases.json` содержит базовые сопоставления исходных листов с группами satu.kz.

`group_cache.json` хранит пользовательские правки названий групп и ID после работы GUI. При запуске из исходников файл находится рядом с `converter.py`; в собранном EXE - рядом с `dist/satu-converter.exe`.

## Сборка EXE

```powershell
cd C:\Users\admin\Desktop\active-firm\converter
.\build.bat
```

Готовый файл:

```text
C:\Users\admin\Desktop\active-firm\converter\dist\satu-converter.exe
```

`build.bat` должен оставлять окно открытым и при успехе, и при ошибке, чтобы пользователь видел результат сборки.
