# Satu.kz Excel Converter

Конвертер берет исходный прайс-лист из Excel и создает новый Excel-файл импорта для satu.kz.
Пользователь выбирает только исходный прайс и путь финального файла.

## Что делает приложение

- читает все товарные листы исходного прайса;
- ищет строку заголовков с колонками `код`, `Наименование`, `Ед. изм`, `Остаток`, `Цена розница`;
- создает новую книгу Excel с листами `Export Products Sheet` и `Export Groups Sheet`;
- заполняет 106 колонок satu.kz по структуре из `satu_schema.json`;
- переносит только те поля, которые можно получить из исходного прайса;
- определяет колонки на каждом листе по заголовкам, а не по фиксированным номерам;
- сопоставляет листы прайса с группами satu.kz через `group_aliases.json`.

## Используемые поля исходного прайса

- `код` -> `Код_товара`, `Уникальный_идентификатор`
- `Наименование` -> `Название_позиции`, `Поисковые_запросы`, основа `Описание`
- `Ед. изм` -> `Единица_измерения`
- `Остаток` -> `Наличие`
- `Цена розница` -> `Цена`
- цена для постоянных клиентов -> `Оптовая_цена`
- дополнительный комментарий -> часть `Описание`
- числовой остаток, если есть -> `Количество`
- имя листа -> группа satu.kz через `group_aliases.json`

Остальные колонки satu.kz остаются пустыми, потому что в исходном прайсе для них нет надежных данных.

## Установка

```powershell
cd D:\Projects\active-firm\converter
python -m pip install -r requirements.txt
```

## Запуск GUI

```powershell
python .\gui.py
```

В окне выберите:

- исходный прайс;
- путь финального файла.

После успешной конвертации приложение покажет окно с путем до результата.

Если на листе найдены товары без кода, приложение спросит, включать ли их в выходной файл. В этом окне можно отметить `Применить этот ответ ко всем последующим листам`.

## Запуск через командную строку

```powershell
python .\converter.py "..\Копия Прайс от 12.05.26 ААА.xlsx" -o ".\output\satu-products.xlsx"
```

По умолчанию CLI пропускает товары без кода. Чтобы включить такие строки:

```powershell
python .\converter.py "..\Копия Прайс от 12.05.26 ААА.xlsx" --include-without-code -o ".\output\satu-products.xlsx"
```

## Конфигурация

`satu_schema.json` содержит:

- порядок колонок листа `Export Products Sheet`;
- список групп для листа `Export Groups Sheet`.

`group_aliases.json` содержит сопоставления листов исходного прайса с группами satu.kz.

Если листа нет в `group_aliases.json`, конвертер ставит названием группы имя листа, а номер группы оставляет пустым. После запуска программа показывает список таких групп и количество товаров в каждой.

## Сборка GUI в .exe

Самый простой вариант:

```powershell
.\build.bat
```

Ручная команда:

```powershell
cd D:\Projects\active-firm\converter
python -m pip install -r requirements.txt
python -m pip install pyinstaller
python -m PyInstaller --clean --onefile --windowed --name satu-converter `
  --add-data "group_aliases.json:." `
  --add-data "satu_schema.json:." `
  gui.py
```

Готовый файл будет создан здесь:

```text
D:\Projects\active-firm\converter\dist\satu-converter.exe
```
